# Security policy

Please report security-sensitive problems privately to dingwei@iphy.ac.cn with the subject `OASIS4.3-GUI security`. For ordinary bugs and scientific-result questions, use the repository issue tracker. Do not attach confidential diffraction data or unpublished structures to a public issue.

Only the current `0.1` release line is supported. Reference downloads require HTTPS and fixed SHA-256 checksums; a checksum failure stops installation without replacing a valid cache.
